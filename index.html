Inside the game

An empire worth building.

From your first planet to a growing fleet, the game combines resource management, research, alliances, and a universe of destinations.

01 / EXPAND

Planets & research

Manage resource production, develop buildings, unlock technologies, and move between planets and moons.

02 / COMMAND

Fleet management

Choose ships through compact icon cards, set quantities, and prepare missions with familiar fleet controls.

03 / CONNECT

Profiles & alliances

Explore player profiles, compare rankings, join alliances, and communicate through the game.

04 / UNDERSTAND

Clearer game data

Compact resource and score displays keep large numbers readable while preserving full calculation values.

05 / ADMINISTER

Seed a new universe

Administrator-managed NPC accounts grow resources and fleets. Pause or resume growth through the control panel.

06 / REFINE

Practical improvements

Accessible notices, registration protection, language corrections, and targeted fixes improve everyday play.

Make it yours

Start with the source.

The repository contains the game server, installer, administration panel, templates, scripts, dependencies, and tests. The website you are viewing is a static presentation.

The game requires a PHP server and a database. The verified development runtime is legacy PHP 7.2; full PHP 8.4 migration is still in progress.

Read runtime status ↗

  1. Get the releaseDownload the source package or clone the repository. Application files live in download/.
  2. Prepare your environmentSet up PHP, PDO MySQL, GD, and an empty database. Use your own instance credentials.
  3. Install your universeRun the installer, create your administrator, and configure the game and cron tasks.
  4. Verify and customizeCheck resource updates and user flows. Review the included image rights before deployment.
