# Security

This project is a prerelease with legacy runtime and dependency constraints. The repository does not claim comprehensive security certification or complete PHP 8.4 readiness.

Please report suspected vulnerabilities privately to the maintainer through the contact route listed on the [4lin GitHub profile](https://github.com/4lin). If private vulnerability reporting is enabled on the repository, use that feature. Avoid posting credentials, private instance URLs, account data, or working exploit payloads in public issues.

Include the affected version, runtime, relevant configuration with secrets removed, reproduction steps, and expected impact. Public release notes should describe the fix without exposing private reports or credentials.
